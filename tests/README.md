# 测试体系

```
make test        # 快速套件（约 3 分钟）
make test-full   # 完整套件，含 20 万变量 / 100 万子句规模
make sanitize    # 快速套件，跑在 ASan + UBSan + libstdc++ 断言构建上
make mutation    # 变异测试
```

也可以直接调用：`python3 tests/run_all.py [--quick] [--only fuzz,checker] [--bin-dir build/san] [--json out.json]`。

## 原则

**没有任何一个答案是凭求解器自己的话被接受的。** `tests/common.py` 的 `certify()` 是所有测试的入口：

* 求解器说 SAT → 赋值交给 `checker/model_check`（C++）和 `tools/cnf.py`（Python）各代入一次；
* 求解器说 UNSAT → 证明交给 `checker/rup_check`（C++）；抽样再交给 `checker/rup_check.py`（朴素参考实现）
  和"忽略删除行"模式各检查一次；
* 若实例的真值由构造方式或暴力枚举已知，答案必须与之相符；
* 退出码、状态行、证书三者必须一致。

超时**不算**通过也不算答案错误：容易实例超时记为失败，困难实例超时如实报告。正确性从不以耗时判断。

## 测试组

| 组 | 文件 | 内容 | 判定依据（独立于求解器） |
|---|---|---|---|
| A | `test_fuzz.py` | 数万个 0–18 变量的不规则小公式（空子句、单位子句、重复文字、重言式、重复子句、未使用变量）；抽样对 14 种消融配置重跑 | 暴力枚举 `tools/brute` |
| B | `test_constructive.py` | 先定隐藏赋值再生成子句（必 SAT）；再混入自相矛盾的小部件（必 UNSAT）；隐藏的鸽巢核 | 构造方式 |
| C | `test_families.py` | 鸽巢、图着色、阈值附近随机 3-SAT、隐藏解、长传播链、大量重复、奇偶约束、序原理；分 easy / hard 两档 | 构造方式 + 证书 |
| D | `test_metamorphic.py` | 变量重命名（含极性翻转）、子句/文字乱序、加重复子句、加重言式、加无关变量、全部叠加 | 变换前后结论必须相同 |
| E | `test_checker.py` | 手写证明与手写赋值（各有预期结论）；随机破坏的证明要求 C++ 与 Python 检查器结论一致；对可满足公式提交"几乎正确"的证明必须拒绝 | 参考检查器 + 暴力枚举 |
| F | `test_incremental.py` | 同一进程回答多组假设查询；模型、冲突核、会话证明逐一验证；倒序并重复查询后结论不变 | 暴力枚举 / 全新的已认证求解 |
| G | `test_cli.py` | 输入格式的边界情况；三个独立读取器对合法输入一致、对非法输入全部拒绝；资源上限返回 UNKNOWN | 手写预期 |
| H | `test_scale.py` | 规模上限实例；记录时间、内存、证明大小、检查时间；求解器内存不得超过 1 GiB | 构造方式 + 证书 |

## 变异测试

`tests/mutation.py` 含 50 个人为植入的错误，每个是源代码中的一处文本替换（替换目标必须恰好出现一次，
否则报错，避免变异体悄悄失效）。对每个变异体：复制源码 → 打补丁 → 编译 → 用 `--fail-fast` 跑快速套件。

类别：文字取反错误、遗漏传播、空子句处理、状态恢复、忽略冲突、错误的学习、子句库维护、证明记录、输出、
**检查器错误接受非法证明**、赋值检查器错误。

运行前先做对照：未打补丁的源码以相同方式编译后必须通过全部测试，否则结果无意义。

幸存的变异体不等于测试有漏洞——有些改动不改变任何答案（等价变异体）。每个幸存者的人工结论见
`docs/RESULTS.md`。
